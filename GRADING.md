# Grading rubric (suggestion)

## Part I (15p)
- I.1: 5 items × 2p = 10p
- I.2: 5 answers × 1p = 5p

## Part II (40p)
### Problem 1 (20p)
- Parsing correctness + validation: 8p
- Category totals correctness + rounding: 7p
- Top spender logic + ties + empty input: 5p

### Problem 2 (20p)
- Correctness on typical cases: 10p
- Edge cases (empty, all negatives, multiple answers): 5p
- Complexity / efficient approach: 5p

## Part III (20p)
- Issues identified (min 6): up to 8p
- Correct fix: 8p
- Tests: 4p (coverage matters)

## Part IV (25p)
- Book validation + is_borrowed default: 5p
- Book __str__: 3p
- Library add_book (no duplicates): 4p
- find_by_author: 3p
- borrow: 3p
- return_book: 2p
- available_books: 0.5p (or include in others)
- library_summary: 5p

Tip: Use hidden tests for corner cases (whitespace, mixed-case titles/authors, repeated borrow/return).
